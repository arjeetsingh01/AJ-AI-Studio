# 🤖 AJ AI Studio

AJ AI Studio is an all-in-one AI workspace designed to bring multiple AI-powered tools into one modern and responsive platform.

## ✨ Features

- 🤖 AI Chat
- 📝 AI Summarizer
- 🌐 AI Translator
- 📄 AI Resume Builder
- 📧 AI Email Writer
- 💻 AI Code Assistant
- 🖼️ AI Image Generator
- 📚 AI Document Q&A
- 📊 User Dashboard
- 🕘 Chat & Tool History
- ⚙️ User Settings
- 🔐 Secure Authentication

## 🛠️ AI Tools

### AI Chat
Chat with the AJ AI assistant and get helpful responses.

### Summarizer
Convert long text into clear and concise summaries.

### Translator
Translate text into different languages.

### Resume Builder
Generate professional resume content using your information.

### Email Writer
Create professional emails with different tones.

### Code Assistant
Get help with programming code, debugging and improvements.

### Image Generator
AI image generation feature.

### Document Q&A
Upload a document and ask questions about its content.
